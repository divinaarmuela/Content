## The flow (video edit cards)

In Progress → Quality check → **Colour grade** → With client → **split** → For Handoff / a new **Round N** card → Done

| # | Rule | Decided by |
|---|------|-----------|
| C1 | Every VIDEO edit card passes the quality check into **Colour grade**, never straight to the client. Design (graphics) cards, shoot plans and internal tasks skip it, as today. | owner: "Every video edit" |
| C2 | The quality check is whole-batch: pass the whole card to colour grade, or send the whole card back (today's send-back). | owner |
| C3 | **Colourist** is a tick on the Team page, like Quality reviewer. Martin K is ticked. Colourists are told when a card reaches colour grade; nobody ticked → super admins are told. | build |
| C4 | At colour grade the colourist hands in a Google Drive link of the graded videos (the same "Hand in from Google Drive"). The graded set REPLACES the editor's files for this version — the client sees graded videos only. | owner |
| C5 | **Put it on the client's portal** — the colourist (or a manager) presses it once a graded hand-in has landed for this version. Never before; never while files are still copying. | owner: "Martin" |
| C6 | Split, two doors: the client presses **Send my answers** on the portal, or a manager presses **Split** on the card. | owner: "either" |
| C7 | The split: approved videos stay on the card, which goes to **For Handoff** (and auto hand-over, as today). Videos not approved leave this card and become a new card **"<title> · Round N"** for the same editor, In Progress, with the client's comments per video, and the editor is told "Upload a new Drive link with these videos". | owner |
| C8 | All approved → no split, the whole card to handover. None approved → no split, the whole card back to the editor (today's send-back). | build |
| C9 | The Round N card is a fresh card: same client, shoot, work kind, editor and Drive folder to work from; its own Drive hand-in; the same flow (quality check → colour grade → client). | owner |
| C10 | Cards already past the quality check at launch (the 9 with clients) skip colour grade. They split only on a deliberate press (C6) — nothing about them moves on its own. | build (owner: "idk") |
| C11 | The client is never emailed by any of this (the client-email rule). Team notices only. | owner rule |

## Who may do what

| Move | Who |
|------|-----|
| Quality check → Colour grade | quality reviewer, super admin |
| Hand in the graded Drive link at colour grade | colourist, account manager, super admin |
| Colour grade → client ("Put it on the client's portal") | colourist, account manager, super admin |
| Colour grade → back to the editor | colourist, account manager, super admin |
| Split | the client (Send my answers), account manager, super admin |
