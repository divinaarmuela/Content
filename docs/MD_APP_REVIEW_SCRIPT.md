# MD App — Meta App Review recording script

Written 9 Nov 2026. One short clip per permission, recorded from one long session cut into pieces.
Every step below was checked working on the test client on 9 Nov 2026 except where marked **(first time on camera)**.

## Before you press record

- Browser: Chrome, window 1440 px wide or less, zoom 100%, cursor enlarged (Windows: Settings → Accessibility → Mouse pointer → size 2).
- Recorder: 1080p, **no audio**. Add captions afterwards (the caption text is given for each step).
- Logged OUT of app.mdmmarketing.com.au at the start of the first clip.
- Facebook logged in as **Martin Kormushoski** (MD App admin). Second browser profile/phone logged in as **Akmal Ashwin** (sends the Facebook comment and Messenger message) and Instagram as **crab.6373122** (Instagram Tester; sends the Instagram comment and DM).
- Zernio's comment automation on @testbusinessaccount2026 is **OFF**. Nobody comments "TEST" or "LINK".
- Messages must be **less than 24 hours old** when replied to. Send fresh ones from Akmal and crab.6373122 shortly before recording if the 9 Nov ones (2:44 pm and 3:07 pm) have expired.
- Use the **Table booking** form for leads. Delete the earlier test lead in Meta's Lead Ads Testing Tool first (it allows one lead per form).
